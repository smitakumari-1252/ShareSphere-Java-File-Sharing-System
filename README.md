ShareSphere – Java-Based File Sharing System

ShareSphere is a Java-based desktop application that allows users to securely share and manage files through a client-server network.

Features

- User Registration and Login
- Secure Password Hashing
- File Upload and Download
- View and Delete Files
- Individual User File Storage
- Multiple Client Connections
- Upload/Download Progress Bars

Technologies Used

- Java
- Java Swing
- TCP Socket Programming
- Multithreading
- File Handling

Project Type

Java and Computer Networking Academic Project.
